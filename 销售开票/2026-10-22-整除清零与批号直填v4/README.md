**2. 导入提速（只做可证明等价的消除）**：逐行远程取证后确认——限销配置查询 `uf_sql_SpKhSale` 原来每个明细行查一次，其 SQL 只读配置表 K_SpKhSale、导入内不可能变。本版改为一次导入内按商品缓存复用。mock 计数：6 Excel 行/3 商品/9 明细行场景远程 21→15 次（限销 9→3），逐行快照与完成提示逐字一致；全不同商品场景 16→16，如实无收益。查到但没动的：第二遍复位时平台库存校验逐行触发（改之动校验语义）、平台证照校验逐行调用（保护库不可证可缓存），已在报告中列明。

**3. Excel 填了批号仍走分摊 → 改为直填**：取证为三层丢失（粘贴只读两列、导入数据集无批号字段、有数量即无条件全量分摊覆盖）。v4：粘贴支持第三列批号、导入表格新增「批号」列；带批号且可用库存充足（口径同表单选批号窗口：账面−已占用−销售占用）的行**不走分摊、按所填批号直接成行**（分摊全链 0 调用）；可用不足或查无此批号的行按 Alan 拍板口径**整行回退原分摊并在收尾提示点名**；同单同批号多行按行累计占用防超额；没填批号的行分摊流程逐字不变。
