## 内容

针对"保存直退直销后，销售开票查询/销售退回通知查询/销售出库查询查不到生成的单"：按三个查询表单的 SQL 硬条件逐项核对生成语句，补三处主表 insert 缺失的 K_BillSrcPt（开票查询强制平台权限过滤卡此字段，原为空必查不到），K_Factory 改为源单优先 COALESCE（原只取表头、为空即被工厂权限过滤），两处回写源出库单的 update 加 nvl 防冲空（避免源单原值被表头空值抹掉后从出库查询消失）。经表结构核查，KF_IsClose、BillState 有默认值兜底，未动。

## 现场验证点

保存一单直退直销后：销售开票查询能查到生成的开票单（明细也能打开）、销售退回通知查询能查到退回通知单、销售出库查询里源出库单仍在且工厂/业务类型未被改空。注意生成单据的日期沿用源出库单日期，按操作当天范围查不到属原口径（文档有说明）。
