# xfy-packages（欣福源项目交付包仓库）

本仓库专门存放交付包 zip，与代码/文档仓库 Alang1234567/-xfyproject 分开：那边放源码、文档、表结构与过程存档；这边只放可直接部署的包文件。

## 分类规则

- 路径：`<表单>/<日期-主题>/`，如 `销售开票/2026-10-21-提取字段修复-v4/`。
- 每个文件夹放：交付 zip 本体 + 一份 README（改动说明、SHA-256、源码位置、现场验证点）。
- 新版本开新文件夹，不覆盖旧版文件夹；被取代的版本在 README 中注明。
