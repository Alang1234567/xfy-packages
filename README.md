# xfy-packages（欣福源项目交付包仓库）

本仓库专门存放交付包 zip，与代码/文档仓库 Alang1234567/-xfyproject 分开：那边放源码、文档、表结构与过程存档；这边只放可直接部署的包文件。

## 直退直销

- `直退直销/2026-10-21-全字段补全-v3/`：直退直销 v3（包含 v1 全部内容 + 全字段补全：源单同名业务属性全量对齐、批号族关联带入、退回通知单平台列错误字段名纠正），**现行交付版**。
- `直退直销/2026-10-21-查询可见性补全-v2/`：直退直销 v2，**有重复列缺陷，请勿部署**，已被 v3 取代。
- `直退直销/2026-10-21-提取与保存校验修复-v1/`：直退直销 v1（提取列表/明细可退量过滤启用、保存超退校验接通 uf_sql_yd、after_save 幂等守卫），已被 v2 取代。

## 分类规则

- 路径：`<表单>/<日期-主题>/`，如 `销售开票/2026-10-21-提取字段修复-v4/`。
- 每个文件夹放：交付 zip 本体 + 一份 README（改动说明、SHA-256、源码位置、现场验证点）。
- 新版本开新文件夹，不覆盖旧版文件夹；被取代的版本在 README 中注明。
