# 销售退货协议书 · 打印模板接法说明

> 模板文件：`销售退货协议书打印模板.rpt`（本目录）；配套表单包：**v5.6**（查询明细补原发票号/原发票日期两列，模板的开票日期/发票号码靠这两列供数，必须配套，旧版表单包预览这两列为空）。

## 一、打印姿势（Alan 定 B 口径）

在「已申请数据的查询」页签提取 → 打开（点开）一张**红字**申请单（明细装载该单已申请行）→ 点表单现有的「打印预览」按钮。模板只对红字单有意义；蓝字单打开时打印，原发票两列为空、量额为蓝字口径，不要用。

## 二、模板结构与字段映射

A4 纵向，左右边距各 10mm。带区：标题带（标题＋甲乙双方＋引言＋「一、货物描述：」）→ 页眉带（11 列表头，跨页重复）→ 主数据带（ds_qdt 逐行）→ 报表汇总带（合计行＋二~六条款＋备注＋双签章）。

| 协议列/位置 | 模板表达式 | 来源 |
|---|---|---|
| 甲方（购货方） | `[ds_qmt."客户名称"]` | 查询主表当前行 |
| 序号 | `[Line#]` | 明细行序 |
| 开票日期 | `[ds_qdt."原发票日期"]`，格上 DisplayFormat 日期型 `yyyy-mm-dd` | **v5.6 新增列**：原蓝票 InvoiceMt.InvoiceDate（真日期型供数，故设日期显示格式定型） |
| 发票号码 | `[ds_qdt."原发票号"]` | **v5.6 新增列**：原蓝票 InvoiceCode（与红字页「原发票号」同口径子查询：只取有效蓝票） |
| 货物名称 | `[ds_qdt."商品名称"]` | |
| 规格型号 | `[ds_qdt."商品规格"]` | |
| 单位 | `[ds_qdt."单位"]` | |
| 数量 | `[ABS(ds_qdt."已申请量")]`，格式 `0.##` | 已申请量（红字存负数，ABS 打正） |
| 含税单价 | `[ABS(ds_qdt."含税单价")]`，格式 `0.00##` | |
| 含税金额 | `[ABS(ds_qdt."已申请额")]`，格式 `0.##` | 已申请额 |
| 税率 | `[ds_qdt."税率"]`，格式 `0.##` | 原样数字（如 9 表示 9%），未加 % 号 |
| 商品税收分类编码 | `[ds_qdt."税务分类编码"]` | |
| 合计金额 | `[ABS(ds_qmt."已申请金额")]`，粗体 | 主表整单已申请额（与明细逐行合计同值，不走报表聚合、无出 0 风险） |
| 乙方、引言、二~六条款、备注、签章/日期 | 固定文字 | 按 Alan 2026-10-28 协议图逐字转录；退货原因留横线手填 |

版式细节：正文宋体 11pt、标题 16pt 粗体、表格 9pt（税收分类编码 8.25pt 防 19 位编码溢出）；货物表全边框；合计行标签合并前 8 列。与原图的已知偏差：原图 5 个表头单元格的**黄底未复刻**（判断是原 Word 里的标示，非版式要求；要保留说一声即可加）。

## 三、挂载（重要：模板位只有一个）

本表单的打印模板位只有一个，现挂的是《开票申请单打印模板》（A5 那张）。把本 .rpt 替换进去后，打印预览出的就是退货协议书，开票申请单那张即不再是当前模板——**二选一挂载**，切换就是在设计器/平台里换模板文件，表单包本身不携带模板。若两张都要常驻使用，需要另想挂法（例如协议书挂到另一个表单），先按替换用着，不合再说。

表单侧无需新增接线：打印预览按钮已在（`Printer.preview()`），本次 v5.6 只补数据列、不动按钮与脚本。

## 四、现场预览核对点

1. 选一张已申请的红字单：甲方=该客户、货物行=已申请行、数量/金额为正数、合计=该单已申请金额；
2. 开票日期/发票号码=原蓝票的日期/号码（对照红字页明细的「原发票号」应一致）；若这两列空白，先确认导的是 v5.6 表单包，再确认原单确实开过蓝票；
3. 条款文字与原图逐字核对一遍（转录自图片，如有个别字出入告诉我改）；
4. 若某个 ABS 表达式格报错或空白（平台报表引擎函数差异），把现象告诉我，改走负号处理的其他写法。
