# 开票申请单打印模板 · 修复版说明（2026-10-28）

- 基线：Alan 上传的现行模板文件 `upload-2.rpt`（即终版经平台设计器重存过的版本）。
- 产物：`开票申请单打印模板-修复版.rpt`（11,105 B）。与基线相比**只有 5 个单元格不同**，带区、页面、列网格逐字未动（已用脚本对账）。

## 先说清截图那张是怎么回事

Alan 17:02 的预览截图里，明细无边框、无绿底、无序号、列错位、行尾多「普票」——
但他随后发来的模板文件里，七列网格、全边框、浅绿底、序号**全都在**（就是终版那套）。
所以截图那张是服务器上还挂着的**另一份旧模板**打出来的；把本修复版替换到模板位，版式即按文件这套走。

## 本修复版改的 5 个格子

基线文件被设计器打开保存过一遍，有 3 个格子的表达式被清空（Text=""），另 2 个格子按截图里已在用的形态补绑：

| 格子 | 基线状态 | 修复 |
|---|---|---|
| 申请时间值（Memo3） | 表达式与日期格式被清空 | 恢复 `[ds_qmt."申请时间"]` + DisplayFormat 日期型 `yyyy-mm-dd`（第三版定案） |
| 汇总行标签（Memo23） | 被清空 | 恢复 `[ds_qmt."客户名称" + ' 汇总']` |
| 汇总金额（Memo24） | SUM 与数字格式被清空 | 恢复 `[SUM(ds_qmt."已申请金额")]` + 格式 `0.##`（照设计器方言只带 FormatStr，与明细金额格同式） |
| 特殊情况说明值（Memo26） | 空（原设计手填） | 绑 `[ds_qmt."备注"]` 并加粗（照截图形态；若实际填在「摘要」里，说一声即换） |
| 申请人值（Memo28） | 空（原设计手填） | 绑 `[ds_qmt."申请人"]`（截图里蒋艳即此字段） |

## 使用

在设计器/平台把本文件替换到本表单的打印模板位即可，**不用动表单包**。
替换后预览核对：申请时间格有日期、每客户一组末尾有「客户名 汇总 + 金额」、特殊情况说明出备注内容、申请人出名字。
注意：若之后再用设计器打开本模板并保存，留意那 3 个格子是否又被清空（本次即是这样丢的）——
交付文件留底在 xfy-packages，丢了可随时取回。
