## 二、红字落点取证结论：不加列，与蓝字共用 SaleOut 申请列

1. **红字数据源不是发票登记表**：参照表单红字页宏 `S_RedInvoMt`/`S_RedInvoDt` 的数据源与蓝字同为 `SaleOutMt/SaleOutDt`，区别仅在过滤：退货类单据 `a.RuleId in ('1w8bnrjr7c7no0bj','3cc08h3z7cnkrv2q')`（该组 RuleId 亦见于函数库 pf_InvoUpdSrc 等 5 个函数的源单回写分支）。已登记/已开具的关联（原蓝字发票号、对应蓝字发票行 K_ReBlueLine）是经 `InvoiceMt/Dt`（登记规则 `3efz6zl30gj7qi9e`、未冲红口径）**回查展示**，不是申请落点。
2. **InvoiceMt/InvoiceDt 无可复用闲置字段**：InvoiceMt 88 字段、InvoiceDt 50 字段逐项核查，无「申请」语义字段；红字族字段（isch/ChongHong/ChongHongNum/ChongHongAmt/chbillno/K_ReBlueLine、专票红票信息表编号 hpxxbbh 等）全部在役（整张冲红与登记回写在用），不合「注释吻合 + 零引用」的复用判据。
3. **SaleOut 侧的冲红族字段同样在役**（Mt/Dt 的 isch/ischwc/chnum/chbillno），非闲置，不可挪用。
4. **结论**：红字申请落点与蓝字**共用同一套列**——行级 `SaleOutDt.KF_KFPSQ`（复用闲置列）+ `K_ApplyInvoiceNum/K_ApplyInvoiceAmt`（v1 DDL 已含），单头留痕共用 `SaleOutMt.K_ApplyUser/K_ApplyTime`。方向由单据 RuleId 天然区分：一个单据要么是普通出库（蓝字源）、要么是退货类（红字源），同一行不可能双向申请，不存在串账。**红字新增 DDL = 0 列**（DDL v4 版仅在文件头增补本结论，正文与 v1-v3 相同）。
5. **符号口径**：退货行量额在库中为负数存储——证据为 `S_RedInvoDt` 的 exists 余额判定用 `abs(v1.K_RegInvoiceAmt) < abs(v1.TaxAmount)`，且登记回写对红字行同样累加 K_RegInvoice*（负向）。故红字余额在**绝对值空间**取 greatest：可申请余额 = |含税额| − max(|已登记额|, |已申请额|)（数量同理），与设计 §3.2 的蓝字口径同构；提取宏 BalNum/BalAmt 用 `sign()` 按原行符号呈现。界面填写按「大小」填正数，写回由服务端函数在 `K_Dir='R'` 时自动落负号（与已登记额同符号空间，财务侧登记封顶口径不变）。

**状态推导**（SQL CASE，绝对值空间，蓝红同规）：|已登记额| ≥ |已申请额| 且已申请 > 0 → **已开完**；|已登记额| > 0 → **部分开票**；否则 → **待开票**。（注：撤销后申请额被降至已登记额，已开完的行仍会留在本页，属真实台账状态；从未申请过的行不进本页。整张发票冲红与手动登记两页按 Alan 定案不在本表单范围——冲红是财务在 15dka 的动作，手动登记与蓝字页在本表单同构、已被蓝字页覆盖。）

**查询头**（三页共用，沿用 v3 两行）：客户名称 / 业务员 / 出库单号 / 开始日期 / 结束日期。红字页的「出库单号」条件匹配的是退货单号本身（BillCode），原出库单号为展示列不作条件——与参照红字页以退货单为主单的口径一致。

**版面几何**：查询头（0..85）之下为 tabbox（top 93、高 651、底边 744，与 v3 网格同位同底边）；每页签一张行级网格（面板内 0,0 起、1168×605、右/下边距各 16），页签写法（tabbox/tabs/tabpanels/tabpanel + display:none）逐式对齐 15dka。

## 七、注意事项

- **前置 DDL 不变**：仍是蓝字那 4 列（红字 0 新增）；未执行时三页签提取都会报 ORA-00904（K_APPLYINVOICEAMT 等标识符无效），属预期。
- 若现场发现某退货行量额为**正数存储**（与负数存储证据相悖的个别历史数据）：提取的余额列经 sign() 仍按该行符号呈现、大小口径校验不受影响；但写回按红字约定落负号，与该行既有正数已登记额符号不一致时请回告，不要强行保存——先核对该行 K_RegInvoice* 的实际符号再定。
- 服务器直建版 `1qnyaq9q8shnwbas`（v1.1.82.2）仍为单页蓝字版，**未同步三页签**；如需服务器版也升三页签，另行授权后按「打开→保存」流回写（勿用新建流载荷）。
- 运行时页签标题取菜单节点名一事与版面无关：本表单的三个**内页签**标题在包内（蓝字发票申请/红字发票申请/已申请数据的查询），不受菜单命名影响。
