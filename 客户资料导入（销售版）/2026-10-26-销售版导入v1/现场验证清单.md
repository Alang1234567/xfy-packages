# 现场验证清单：客户资料导入（销售版）v1

导入顺序：先导**包二**（客户资料入口版，覆盖 2p1teo 实例）→ 再导**包一**（新表）→ **关掉客户资料与新表的全部已打开页签（或重登）再测**。两包导入后先在测试户上走一遍，不要直接拿全量台账首跑。

## A. 导入与挂载

- [ ] A1 包一导入后菜单/表单列表能找到「客户资料导入（销售版）」，打开不报错，网格上方 57 列 + 状态列（匹配/校验结果/问题原因）、下方问题单网格都在位。
- [ ] A2 包二导入后，客户资料工具栏「辅助功能」菜单出现「客户资料导入（销售版）」，点击能打开新表（打开方式 `form.open(..., 'new', ...)` 为平台既有写法在 2p1teo 语境下的套用，**未在本站实测过**——若打不开或模式不对，回传现象，不要自行改包）。
- [ ] A3 新表是否需要单独的菜单挂载/权限分配（各站口径不同）：若业务员账号看不到入口，按本站权限流程给新表 formid `hoi5z8fazwvvmr5v` 授权。

## B. 平台机制类（设计 §6 遗留，只能现场证）

- [ ] B1 模板导出产物格式：`grid1.exportTo(0)` 导出的文件扩展名与可打开性（应含示例行 EXAMPLE）；用该文件改数后能被导入识别。
- [ ] B2 `FormUtil.importFile` 对 .xls / .xlsx 两种格式的接受度；**首行表头是否被平台跳过**——本包服务端按「编号格=EXAMPLE 或 客户编号 字面量」双保险跳过示例/表头行，若平台已剥离表头也不受影响，现场任选一份带表头文件验证暂存行数与 Excel 数据行数一致。
- [ ] B3 单次导入行数上限与大文件（数千行）耗时：先 50 行、再 500 行试，记录保存阶段耗时。
- [ ] B4 暂存表 `t_hoi5z8fazwvvmr5v_ds_Client` 首用是否自动建表（平台 temptable 机制预期自动建；若报「表不存在」，回传报错原文）。
- [ ] B5 `saveDatasets` 对更新户是否按 keyfield（businessid）走 UPDATE 而非重复 INSERT：导一份只有存量户的 Excel，保存后查 BusinessDoc 行数不变、字段按覆盖口径更新。
- [ ] B6 服务端回调注入的全局名 `dataset` / `EntId` 与参数键大小写跟原厂 3mqc 在本站一致（原厂同名实证，预期无问题；若导入回调报未定义，回传原文）。

## C. 业务验收用例（建议按序跑）

- [ ] C1 **新户全量行**：照示例行造 1 户新客户（带证照编号+到期日、采购员、代理人、销售员单账号人员、内勤），保存后到客户资料里打开该户核对：类别/账期/事业部/大区/税票分类/价格体系/业务来源/业务平台均为名称转码后的值；经营范围在客户资料页正常回显；首营状态为待审批（IsPass 未通过）；默认地址行存在且 DftAddress 指向联系地址。
- [ ] C2 **证照落点**：C1 户的证照在客户资料证照子表可见（经营许可证编号/有效期）；购销合同到期日同步到主表合同终止日期。
- [ ] C3 **联系人落点**：C1 户的采购员/代理人子表单各有 1 行，姓名与 Excel 一致。
- [ ] C4 **更新户**：拿一户存量客户，Excel 里改开户户名、证照只给新到期日、名称故意写错一字、授信额度 ±1 内微调：保存后核对——户名已更新、证照日期更新且编号不变、**名称仍是库内原名**、授信仍是库内值；问题单出现「黑名单名称待核」。
- [ ] C5 **拦截户**：造 1 行（类别填字典外名称 + 不填联系电话）与 C4 同批导入：C4 正常落库，C5 整户留在网格、问题单有「字典外值（拦截）+ 必填缺失（拦截）」；把 C5 改对后直接再点保存可落库。
- [ ] C6 **R-P2**：采购员姓名格填 `00:00:00`（Excel 里把单元格设成时间格式再导）：保存后该户无采购员行，问题单有「时间型垃圾值」。
- [ ] C7 **归属**：① 销售员填同名多账号人员、新户、业务来源与其常用客户同类 → 归属自动落到常用账号；② 存量户 Excel 销售员与现归属不同人 → 不改挂，问题单「归属变更待核」；③ 销售员填未建档姓名 → 问题单「未建档人员」，其余字段正常落库。
- [ ] C8 **模板往返**：模板导出 → 不改任何内容直接导入 → 示例行被跳过、无任何落库。

## 已知提示

- 保存汇总弹框即回执：新增/更新户数 + 证照/联系人/归属/地址的增改行数 + 拦截户数；主表已落后段 2~5 补落失败时弹框会明确提示「请勿整批重复导入」，按提示联系处理（重复导入对主表是更新语义，不会重复建户）。
